# style-empty-block-good

The clean half of the pair `style-empty-block` (see `style-empty-block-bad`): the same scripted
effect, every block holding something, in pychivalry's format: the `any_child` with its test
written out (`count >= 1`), the `every_child` and the `liege` with an effect, the `OR` with a
condition, the `random_list` entry and the `switch` case with an effect; and the same event, its
option with an effect. A correct tool reports nothing.
