# fields-missing-required-field-good

The good half of the `fields/missing-required-field` pair: `fields-missing-required-field-bad`
with each record's required field written. A correct tool reports nothing.

The casus belli and the category also carry every field each base-game record of their kind
sets, so that the advice check `fields/usually-present` (item 4.7) has nothing to say about them.
