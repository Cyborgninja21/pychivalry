# scope-wrong-scope-for-trigger-good

The good half of the `scope/wrong-scope-for-trigger` pair: `scope-wrong-scope-for-trigger-bad`
with each trigger moved to a scope it supports, through a link where one is needed (`holder`,
`county`), and the province event's `is_adult` replaced by `is_coastal`. A correct tool reports
nothing.

The decision has a `picture`, as every base-game decision does, so that the advice check
`fields/usually-present` (item 4.7) has nothing to say about it.
