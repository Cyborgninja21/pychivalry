# scope-link-on-wrong-scope-good

The good half of the `scope/link-on-wrong-scope` pair: `scope-link-on-wrong-scope-bad` with each
link applied to a scope it can start from (`holder` after `primary_title`, `root.liege`, and
`title_province` after `capital_county`). A correct tool reports nothing.

The decision has a `picture`, as every base-game decision does, so that the advice check
`fields/usually-present` (item 4.7) has nothing to say about it.
