# Issue triage for 2.0.0

Applied on GitHub on 2026-10-01 (CK3 tooling plan, step 5.2). The 36 issues open that day
(#19 to #87) were judged against the engine-core layering: `close-superseded` where the request
targets code or an approach 2.0.0 removed, `close-done` where the feature exists in the code
(file named), `keep` where the request is still meaningful. Kept issues carry the label `post-2.0`
(created for this) and lost `needs-triage` where they had it. Every closure carries the comment
quoted in the second table. Counts: 20 keep, 11 close-superseded, 5 close-done.

PR #56 (GFX001, a missing-graphics-file diagnostic for the former Python server) stays open:
no engine check or plug-in in 2.0.0 tests whether a referenced graphics file exists (the schema
check validates field names only, and the 1.x `assets.ts` validator with its CK3600 file check
was deleted in Phase 4.3 without a replacement), so the diagnostic is not superseded.
