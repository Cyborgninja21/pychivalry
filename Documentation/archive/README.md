# Documentation archive

Historical documents kept for reference. None of them describes the current code: since 2.0.0
the CK3 vocabulary, schemas and error texts come from the engine-derived spec package in
`packages/engine` (see [the architecture flow](../developer-guide/architecture/ARCHITECTURE_FLOW.md)).
One line per file: what it was, and when it stopped being current.
