# All examples in this file contain unknown/invalid effect keywords.
#
# Error Code Demonstrated:
# - CK3103: Unknown/invalid effect keyword
#
# Common mistakes:
# - Typos in effect names (add_gld instead of add_gold)
# - Made-up effects (give_super_powers)
# - Using triggers as effects (is_adult = yes in effect block)
# - Wrong effect names (fire_event instead of trigger_event)
#
# Expected validation result: ERRORS DETECTED (CK3103 for each unknown effect)
# ===================================================================
