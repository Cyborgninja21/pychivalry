This folder is a Crusader Kings III mod, and it has problems. Use the pychivalry tools to check
the whole mod, then fix every error and every warning the check reports, by editing the mod's
files where the findings point. Look a name up with the tools when you are not sure of it.

Change only what a finding asks for. Do not remove script or text to make a finding go away,
do not add, rename or remove files, and leave alone every line the check does not report.

Check again after your edits. When the check reports no errors and no warnings, stop and say so.
